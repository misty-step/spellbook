# Synthesize

Compile existing observations into useful entity notes and maps. Use
[Daybook](../daybook/SKILL.md) for vault discovery, current note conventions,
source protection and the private context destination. Input is a selected
topic, person, source batch or interview subject; if none is given, use current
priorities to propose a bounded topic before opening sensitive archives.

1. **Survey the selected scope.** Read canonical notes and their raw sources.
   Find uncompiled observations, thin entity notes, stale claims, contradictions
   and open loops. Distinguish an absent record from an absent event. Read
   journal material only when this task needs it; journals remain read-only.
2. **Resolve high-value gaps.** Ask questions anchored in conflicting evidence
   or missing context that would change future assistance. An interview may
   distinguish a fact, self-report, hypothesis or preference. Do not demand a
   broad personal inventory or turn an inference into a confirmed fact.
3. **Compile into existing homes.** Update the relevant entity, area, decision
   or patterns note. Preserve source wording, creation dates and authorship;
   mark agent synthesis and cite sources under the current vault contract.
   Keep unresolved contradictions visible. Supersede an obsolete current claim
   with dated evidence without erasing its history. A proposed idea stays
   context until the user selects work.
4. **Make the result retrievable.** Update the relevant map or current-context
   pointer when its meaning changed. Follow the vault's search-refresh contract
   if needed; inspect side effects before running a refresh. Verify a
   representative question finds the updated source, then record a short
   agent scratch or artifact summary if a durable handoff is needed.

Return the changed note paths, source coverage, resolved and unresolved gaps,
and retrieval result. If the request was only an audit or interview, return
findings or questions without treating it as authorization for broad edits.
Publication follows the selected task and Daybook's current write contract.
