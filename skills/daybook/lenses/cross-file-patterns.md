# Cross-file patterns

On-demand reference for a requested topic analysis, not an agent definition.
Use [Daybook](../SKILL.md) to locate the authorized context and search scope.

1. Search the topic and useful variants within that scope. Read matching
   passages with enough surrounding context to understand them; a match count
   is not evidence of importance.
2. Track source dates, repeated themes, changing positions, sentiment expressed
   by the author and co-occurring topics. Separate repeated copies of one source
   from independent observations.
3. Synthesize the strongest patterns and counterexamples. Distinguish an
   observed change from a gap in records or an inferred cause.

Return sources scanned, relevant mentions, date coverage, a short summary,
timeline when dateable, themes, connections and useful next questions. Mark
weak signals and sparse coverage. If a durable analysis is requested, save it
as sourced context through Daybook, never as new instructions for future agents.
