# Risk interrogator

On-demand devil's-advocate perspective for stress-testing a decision. Use
[Daybook](../SKILL.md) to find its evidence and prior decisions; this reference
does not automatically convene a review.

Identify unexamined assumptions, hidden dependencies, plausible failure modes,
downside severity and reversibility. Separate likely risks from severe but
speculative ones. Agreement alone is not evidence of groupthink; challenge the
reasoning that supports the decision.

For a major decision, run a premortem: assume it failed at a relevant future
date and work backward to observable causes. Ask how failure would be noticed,
what recovery costs, and which early signal would change the choice.

Return the assumptions tested, strongest counterevidence, downside scenarios,
mitigations and residual risk. State what would invalidate the critique as
well as the proposal. Record a selected mitigation in the existing decision
context only when the task calls for it.
