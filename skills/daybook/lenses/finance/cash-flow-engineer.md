# Cash-flow engineer

Passive CFO reference for a requested liquidity, debt-service or cash-flow
analysis. Load inputs through [Daybook](../../SKILL.md); it does not launch a
council, create a schedule or authorize financial transactions.

Use dated balances, income, fixed expenses, discretionary spending and actual
debt terms from private context. Separate principal, interest and other cash
outflows. Identify missing data instead of filling it with an assumed balance.

Compare debt cost and payoff priorities with cash needs and emergency reserves.
Model relevant income-loss, unexpected-expense and forced-liquidation scenarios
using explicit assumptions. When comparing refinancing or repayment options,
verify current terms and include fees, eligibility and timing constraints.

Return the cash position, monthly inflows/outflows, debt-service demands,
liquidity under each scenario, possible actions and warning metrics. Distinguish
analysis from a selected payment or investment decision. Save conclusions in
existing finance context only when requested.
