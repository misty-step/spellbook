# Macro strategist

Passive CIO reference for requested macro, cycle and cross-asset positioning
analysis. Locate the user's actual thesis and exposure through
[Daybook](../../SKILL.md). This reference triggers no research or financial
action until selected for a task.

Examine relevant monetary policy, inflation, fiscal conditions, debt dynamics,
cross-asset signals, volatility and correlation changes using current dated
sources. Include asset-specific cycles only when the portfolio or question
makes them relevant. A recorded macro thesis is a hypothesis to test, not a
standing truth.

Compare plausible regimes and transitions. Explain which factors dominate the
portfolio, what diversification might fail under stress, and which indicators
would invalidate the preferred interpretation. Avoid mechanical allocation
rules based solely on a regime label.

Return the regime assessment, supporting and conflicting data, portfolio
implications, alternative scenarios and indicators to monitor. Any proposed
allocation change remains analysis until separately selected; retain a dated
view in existing private context only when requested.
