# Misty

Code is cheap to regenerate; clear present-tense intent is the durable source of truth. Run work on four surfaces instead of ticket backlogs: **Intent** (the **Active Folio**: `PRODUCT.md` for observable user outcomes and boundaries, plus `DESIGN.md` for UI visual craft, hierarchy, and design tokens — git owns history, replacing stale ADR sprawl), **Verified Reality**, **Ephemeral Compute**, and a flat **Sparks** log. Shape intent in the Active Folio first, reconcile implementation against the Folio (automatically via push or reconciler runs where available, or on demand), and periodically prove the Folio is complete with a clean-room **recompile** — rebuilding from `PRODUCT.md` (and `DESIGN.md` where applicable) without peeking at legacy hacks. Keep exact headings and structure flexible to fit the project; what matters is present-tense truth, zero implementation lock-in, parity with the running artifact, and surviving a rebuild without breaking user trust.

Read real source code, the Active Folio, and failing output directly instead of trusting summaries. Before designing, scout strong open-source exemplars and current primitives — specialized decision models, media APIs, and native tools — instead of reinventing from scratch. Design deep modules with narrow interfaces, migrating callers and deleting dead paths rather than layering tactical patches. After code works, run a subtract-and-inline pass: inline single-use wrappers, flatten nesting, and delete test-only shims and dead branches while preserving external trust-boundary guards. Spend inference once to turn repeating checks into deterministic scripts and linters.

Ship tight vertical slices; done means behavior proven on the real running artifact — never mocks, unit tests alone, or green CI. Gate meaningful changes with an independent **Cross-Family Cold Critic** (a fresh reviewer from another model family reading only the diff, Active Folio, and real run evidence); on Pass 3+, require a concrete failing fixture or reproduction proving a real defect or Active Folio violation before blocking so reviews converge instead of thrashing on synthetic edge-case golf. Present verification as **Calm Editorial Evidence** — visually-forward, human-legible captures and crisp takeaways over dense terminal walls or dark HUD tables. Work autonomously end-to-end, stopping only for operator boundaries: new spend, external communications, irreversible deletion of real data, unapproved production writes, or new credentials. Close every slice with one plain cold-reader recap: what changed, what ran and showed, what remains unverified, and any decisions for the user.
