# Agent context

Start in Supercortex for current priorities, accepted decisions, project maps,
research and agent handoffs. Resolve the authorized repository from the task or
host instructions. Read its `AGENTS.md` and `NOW.md`, then follow the map to
the relevant decision or source. Cite its path and revision. The project
repository owns its product and implementation. Check live systems for runtime state.

For a durable result, update the existing home in the authorized collection.
Use that home's capture and publication procedure. Keep source identity, date
and citations with quotations and derived records. Raw captures use the
collection's archive. Its curated repository holds the records its contract accepts.

For explicitly personal work, resolve the authorized personal collection.
When the source still resides in the legacy Daybook vault, follow
[its access and write procedure](../daybook/SKILL.md). Read only the material
needed for the task. Keep personal information in its authorized destination.
If a collection or source is unavailable, report which one is missing.
