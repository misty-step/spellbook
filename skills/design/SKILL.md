# Design

Pair `DESIGN.md` with `PRODUCT.md` as the visual half of the **Active Folio** — living present-tense visual craft, hierarchy, typography, spacing, and design tokens kept in exact parity with shipped stylesheets and assets so a clean-room rebuild preserves visual trust without drift. Let `DESIGN.md`'s section layout flex to fit the project; prioritize living truth over rigid templates. Start from the user's primary task and put the most important information and action first, removing every decorative box, eyebrow label, or tagline that structure can replace. Use restrained typography, purposeful whitespace, and consistent spacing and color tokens; avoid generic gradients, neon glows, redundant cards, and visual clichés.

Support both light and dark color schemes with clear contrast, responsive layouts without horizontal overflow, and keyboard-accessible controls. Present verification artifacts, reviews, and summaries as **Calm Editorial Evidence** — visually-forward, human-legible proof (real rendered captures, restrained typography, crisp takeaways) over dense dark HUD tables or raw log walls. Prove every visual change on the real rendered surface across desktop and mobile viewports in both light and dark modes, checking for zero console errors and zero broken states.
