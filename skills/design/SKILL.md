# Design

Start from the user's primary task and put the most important information and action first, removing every decorative box, eyebrow label, or tagline that structure can replace. Use restrained typography, purposeful whitespace, and consistent spacing and color tokens; avoid generic gradients, neon glows, redundant cards, and visual clichés. Support both light and dark color schemes with clear contrast, responsive layouts without horizontal overflow, and keyboard-accessible controls. Keep `DESIGN.md` in exact parity with shipped stylesheets and assets so tokens, fonts, and layout rules never drift. Prove every visual change on the real rendered surface across desktop and mobile viewports in both light and dark modes, checking for zero console errors and zero broken states.
