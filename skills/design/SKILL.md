# Design

Pair `DESIGN.md` with `PRODUCT.md` as the visual half of the **Active Folio** — living present-tense visual craft, hierarchy, typography, spacing, and design tokens kept in exact parity with shipped stylesheets and assets so a clean-room rebuild preserves visual trust without drift. Following the **3-Layer Intent Stack**, keep `DESIGN.md` focused on product-specific visual identity, tokens, and explicit opt-outs rather than restating universal or surface-class baselines; let exact headings and layout flex to fit the project. Start from the user's primary task and put the most important information and action first, removing every decorative box, eyebrow label, or tagline that structure can replace. Use restrained typography, purposeful whitespace, and consistent spacing and color tokens; handle empty and error states gracefully; avoid generic gradients, neon glows, redundant cards, and visual clichés.

Apply universal visual craft everywhere (calm hierarchy, accessible contrast, graceful empty/error states, keyboard controls, zero console/CSP errors) plus conditional surface-class craft unless opted out in Folio Non-Goals: **Web Apps** ship a brand mark, multi-size favicon and Apple touch icon, responsive mobile/desktop ergonomics (`390px` + `1440px` without horizontal overflow), light/dark parity, installable PWA basics (`manifest.webmanifest` + standalone viewport), and clean OG/meta tags; **Native/Desktop Apps** honor OS-native conventions, system theme parity, and clean permissions/clipboard hygiene; **Evidence / Artifact / Retro** surfaces use **Calm Editorial Evidence** — visually-forward, human-legible proof with one focal idea per screen or beat, scannable tables (`<= 4` columns), and zero dark-HUD pill soup or raw log walls. Prove every visual change on the real rendered surface across target viewports and themes with zero console errors and zero broken states.
