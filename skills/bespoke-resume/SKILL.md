# Bespoke resume

Turn verified career material and one posting into a sendable application
package. Use [Supercortex context routing](../misty/context-sources.md) to locate the user's master CV,
search preferences and existing application records. Personal facts remain in
that private context; the master CV wins over legacy resumes when they disagree.

1. **Read the posting and career source.** Capture the role, company, location,
   working mode, required skills and problem to solve. Read the master CV and
   verify claims the package needs. Resolve disputed dates or metrics, or omit
   them. If the posting or career source is missing, request that input.
2. **Choose one positioning theme.** Match the strongest supported experience
   to the role. Record the theme and any compensation, location or other fit
   constraints from the user's current search preferences. Do not invent a
   constraint when none is recorded.
3. **Draft the resume and letter.** Weight experience by relevance, retain
   truthful chronology and education, and use only supported metrics. Keep
   contact details consistent with the user's intended disclosure. A reader
   should infer the chosen theme from the resume alone. The letter connects
   the company problem to concrete proof points without repeating the resume.
   Exclude confidential client information unless cleared for that destination.
4. **Save one package per posting** in the existing private application area:
   `posting.md` (source URL, capture date and requirements), `resume.md`,
   `cover-letter.md`, and `notes.md` (positioning, omissions, unresolved facts,
   fit constraints and follow-ups). Reuse the vault's naming convention.
5. **Update existing search context.** If a requirements ledger exists, add
   this package and meaningful requirement or gap changes there. Update open
   loops only when this application changes them; do not create a new tracking
   system for a single package.

Deliver links to the package and any unresolved fit or factual issues. Check
every factual resume claim against its source and the company/role names
against the posting. Drafting does not authorize submitting the application.
